# مدل داده: مدیریت و انتشار کنترل‌شدهٔ پست‌های وبلاگ

| مشخصه | مقدار |
|-------|-------|
| قابلیت | `001-blog-post-management` |
| تاریخ | 2026-10-19 |
| طرح | [plan.md](./plan.md) |

## موجودیت‌ها

### پست (`Post`)

ریشهٔ اصلی داده در پروژهٔ `Core.Domain`.

| فیلد | نوع | توضیح |
|------|-----|-------|
| `Id` | `Guid` | شناسهٔ پست (R-08) |
| `Title` | `string` | عنوان؛ الزامی، غیرخالی، حداکثر ۲۰۰ نویسه |
| `Body` | `string` | متن؛ الزامی، غیرخالی، حداکثر ۵۰٬۰۰۰ نویسه |
| `AuthorId` | `string` | شناسهٔ نویسنده |
| `AuthorDisplayName` | `string` | نام نویسنده در زمان ایجاد پست (R-14) |
| `Status` | `PostStatus` | وضعیت فعلی |
| `CreatedAt` | `DateTimeOffset` | زمان ایجاد (UTC) |
| `LastModifiedAt` | `DateTimeOffset` | زمان آخرین تغییر محتوا یا وضعیت |
| `LastPublishedAt` | `DateTimeOffset?` | زمان آخرین انتشار؛ پس از خروج از انتشار پاک نمی‌شود (R-17) |
| `LastReturnReason` | `string?` | آخرین دلیل بازگشت (FR-005) |
| `Version` | `int` | شمارندهٔ نسخه برای کنترل هم‌زمانی (R-11) |
| `StatusChanges` | فهرست `StatusChange` | سابقهٔ تغییر وضعیت |

ویژگی محاسبه‌شده: `HasEverBeenPublished` یعنی «آیا پست حداقل یک بار منتشر شده است» و وقتی درست است
که `LastPublishedAt` مقدار داشته باشد.

### وضعیت‌های پست (`PostStatus`)

| مقدار در کد | نام در Specification |
|-------------|----------------------|
| `Draft` | پیش‌نویس |
| `InReview` | در انتظار بررسی |
| `Returned` | بازگشت برای اصلاح |
| `Approved` | تأییدشده |
| `Published` | منتشرشده |

### سابقهٔ وضعیت (`StatusChange`)

هر رکورد، یک تغییر وضعیت پست را ثبت می‌کند.

| فیلد | نوع | توضیح |
|------|-----|-------|
| `Id` | `Guid` | شناسه |
| `PostId` | `Guid` | پست مربوط |
| `ActorId` | `string` | شناسهٔ کاربر انجام‌دهنده |
| `ActorDisplayName` | `string` | نام کاربر انجام‌دهنده (R-14) |
| `OccurredAt` | `DateTimeOffset` | زمان تغییر (UTC) |
| `FromStatus` | `PostStatus?` | وضعیت قبلی؛ هنگام ایجاد پست خالی است |
| `ToStatus` | `PostStatus` | وضعیت جدید |
| `Reason` | `string?` | دلیل؛ برای بازگشت الزامی است |

سابقه فقط افزوده می‌شود و هیچ رکوردی ویرایش یا حذف نمی‌شود، مگر همراه با حذف مجاز پستی که هرگز
منتشر نشده است (FR-003).

### کاربر فعلی (`ICurrentUser`)

قراردادی در `Core.Application` که در پایگاه داده ذخیره نمی‌شود.

| فیلد | نوع | توضیح |
|------|-----|-------|
| `IsAuthenticated` | `bool` | آیا کاربر وارد شده است |
| `UserId` | `string` | شناسهٔ ثابت کاربر |
| `DisplayName` | `string` | نام نمایشی |
| `IsAuthor` | `bool` | نقش نویسنده |
| `IsEditor` | `bool` | نقش ویراستار |

یک کاربر می‌تواند هر دو نقش را داشته باشد.

## روابط

- هر پست دقیقاً یک نویسنده دارد.
- هر پست صفر یا چند رکورد سابقهٔ وضعیت دارد. با حذف مجاز پست، سابقهٔ آن هم حذف می‌شود.

## انتقال‌های وضعیت

نمای کلی:

</div>

```text
(Create)            ──► Draft
Draft               ──Submit──►    InReview
Returned            ──Submit──►    InReview
InReview            ──Withdraw──►  Draft
InReview            ──Approve──►   Approved
InReview            ──Return──►    Returned
Approved            ──Publish──►   Published
Published           ──Unpublish──► Approved
Approved/Published  ──Edit──►      Draft
```

جزئیات هر انتقال:

| اقدام | از وضعیت | به وضعیت | انجام‌دهنده | پیش‌شرط | مرجع |
|-------|----------|----------|-------------|---------|------|
| ایجاد | — | پیش‌نویس | نویسنده | عنوان و متن معتبر | FR-002 |
| ویرایش | پیش‌نویس، بازگشت برای اصلاح | بدون تغییر | نویسندهٔ پست | عنوان و متن معتبر | FR-003 |
| ویرایش | تأییدشده، منتشرشده | پیش‌نویس | نویسندهٔ پست | تأیید پیامد توسط نویسنده؛ بدون نیاز به شمارهٔ نسخه | FR-012، R-11، R-12 |
| حذف | پیش‌نویس، بازگشت برای اصلاح | (حذف) | نویسندهٔ پست | پست هرگز منتشر نشده باشد | FR-003 |
| ارسال | پیش‌نویس، بازگشت برای اصلاح | در انتظار بررسی | نویسندهٔ پست | عنوان و متن معتبر | FR-006 |
| پس گرفتن | در انتظار بررسی | پیش‌نویس | نویسندهٔ پست | — | FR-006 |
| تأیید | در انتظار بررسی | تأییدشده | ویراستار | ویراستار، نویسندهٔ پست نباشد؛ شمارهٔ نسخه برابر باشد | FR-007، FR-013، FR-014 |
| بازگرداندن | در انتظار بررسی | بازگشت برای اصلاح | ویراستار | دلیل غیرخالی؛ شمارهٔ نسخه برابر؛ آخرین دلیل بازگشت به‌روز می‌شود | FR-007، FR-014 |
| انتشار | تأییدشده | منتشرشده | هر ویراستار، از جمله نویسندهٔ پست | شمارهٔ نسخه برابر؛ زمان آخرین انتشار به‌روز می‌شود | FR-008، FR-013 |
| خارج‌کردن از انتشار | منتشرشده | تأییدشده | ویراستار | شمارهٔ نسخه برابر | FR-009 |

هر انتقال دیگری با کد `InvalidStatusTransition` رد می‌شود و وضعیت تغییر نمی‌کند. ویراستاری که
نویسندهٔ پست هم هست، می‌تواند پست خودش را بازگرداند؛ فقط تأیید آن برایش ممنوع است (FR-013).

## قواعد اعتبارسنجی

| قاعده | محل اجرا | کد خطا |
|-------|----------|--------|
| عنوان خالی یا بیش از ۲۰۰ نویسه | Domain | `InvalidTitle` |
| متن خالی یا بیش از ۵۰٬۰۰۰ نویسه | Domain | `InvalidBody` |
| دلیل بازگشت خالی | Domain | `ReturnReasonRequired` |
| انتقال غیرمجاز | Domain | `InvalidStatusTransition` |
| تأیید پست توسط نویسندهٔ خودش | Domain | `SelfApprovalNotAllowed` |
| حذف پستی که قبلاً منتشر شده است | Domain | `DeleteNotAllowed` |
| ویرایش پست تأییدشده یا منتشرشده بدون تأیید نویسنده | Application | `ConfirmationRequired` |
| شمارهٔ نسخهٔ متفاوت یا تغییر هم‌زمان در اقدام ویراستار | Application | `ConcurrencyConflict` |
| نقش ناکافی | Application | `Forbidden` |
| پست دیگران یا پست غیرقابل مشاهده | Application | `NotFound` |

## چه کسی چه پست‌هایی را می‌بیند

| کاربر | پست‌های قابل مشاهده |
|-------|---------------------|
| خواننده (حتی بدون ورود) | فقط پست‌های منتشرشده |
| نویسنده | همهٔ پست‌های خودش در هر وضعیت، به‌علاوهٔ پست‌های منتشرشدهٔ دیگران از مسیر عمومی |
| ویراستار | پست‌های همهٔ نویسندگان در وضعیت‌های در انتظار بررسی، تأییدشده و منتشرشده، همراه با سابقهٔ آن‌ها (FR-011، FR-015) |

## نکات ذخیره‌سازی

- دو جدول: `Posts` برای پست‌ها و `PostStatusChanges` برای سابقهٔ وضعیت.
- نمایه (Index) روی وضعیت و زمان آخرین انتشار برای فهرست خوانندگان و ویراستار، و روی شناسهٔ نویسنده
  برای فهرست نویسنده.
- وضعیت پست به‌صورت متن ذخیره می‌شود تا داده خوانا بماند.
- فیلد `Version` به‌عنوان شمارندهٔ کنترل هم‌زمانی در EF Core تنظیم می‌شود.
